# Slashcmd

An independent catalogue of open-source skills for Codex, Claude Code, Cursor, OpenCode, and other coding agents.

Browse practical workflows, copy the installation command, inspect a test prompt, and open the original public demo on X.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production site is deployed on Vercel at [slashcmd.dev](https://slashcmd.dev).
